# Файлы для итогового задания

Описание приложения
Это приложение разработано для удобного планирования и управления задачами.

Основные возможности:
Создание задач с настройкой даты выполнения, комментариев и правил повторения

Редактирование существующих задач

Удаление задач

Автоматический перенос невыполненных задач на следующую дату

Просмотр списка задач с сортировкой по дате

Поиск задачи по уникальному идентификатору (ID)

Структура проекта:
handlers — обработка HTTP-запросов

models — структуры данных задач

helpers — вспомогательные функции (расчет дат, валидация полей)

constants — константы приложения

database — SQL-запросы и работа с БД (таблица scheduler)

server — подключение к БД и запуск сервера

Дополнительные функции:
Настройка порта сервера через переменную окружения TODO_PORT

Указание пути к файлу БД через переменную TODO_DBFILE

Запуск приложения:
Выполните go mod tidy для установки зависимостей.

Запустите сервер командой go run ..

Сервер будет доступен по адресу: http://localhost:7540

Тестирование:
Тесты API находятся в папке tests. Перед запуском проверьте настройки в tests/settings.go:

go
var Port = 7540  
var DBFile = "../scheduler.db"  
var FullNextDate = false  
var Search = false  
var Token = ``  
Для запуска тестов выполните:

bash
go test ./tests
